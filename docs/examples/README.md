# Sample Annam bill

These demonstration files were generated using `apps.billing.services.issue_bill`
and the shared `billing/_invoice_body.html` template. They contain sample customer,
licence, payment and pricing details, with zero GST for this example. They are not
valid payment or tax documents.

- Open `annam-sample-bill.png` to see the bill immediately.
- Download `annam-sample-bill.pdf` for the one-page A4 print version.
- Download/open `annam-sample-bill.html` in a browser for Print / Save as PDF.

The sample was generated in a temporary local transaction that was rolled back.
No live order, payment or production invoice sequence was changed.
