# Deploying to Render

The repository includes a Render Blueprint (`render.yaml`): one web service, one
Postgres database and one persistent disk, all in Singapore (nearest to Chennai).

## Deploy

1. Push this repository to GitHub.
2. In Render: **New → Blueprint**, choose the repository, and apply.
3. Wait for the first deploy. The first boot creates Annam's kitchen and downloads
   the catalog photos onto the disk in the background (a few minutes); the site
   answers immediately and fills in as photos arrive. Logs show `Downloading up
   to N photos...` and then `Seeded Annam Foods`.
4. Open `https://<service>.onrender.com/` for the storefront and
   `https://<service>.onrender.com/manage/` for the owner admin.
5. The owner password is generated by Render: **annam-foods → Environment →
   `SEED_OWNER_PASSWORD`**. The username is `annam-owner`. Change it after the
   first login, or create a named owner with `manage.py provision_tenant`.

## Costs

The web service uses the `starter` plan because the persistent disk (dish photos
and owner uploads) requires a paid instance, and Postgres uses `basic-256mb`
because the free database is deleted after 30 days. Edit the `plan:` lines in
`render.yaml` to change them; check render.com/pricing for current prices.

## How it works

- `build.sh` installs `requirements.txt` and runs `collectstatic`.
- `start.sh` runs migrations, seeds the kitchen on the very first boot only
  (`SEED_ONLY_IF_EMPTY=1`, so a redeploy never overwrites the owner's edits),
  then starts gunicorn. WhiteNoise serves the static files.
- Photos and uploads live on the disk at `/var/data/media` and are served by
  Django (`SERVE_MEDIA=1`). Move to a bucket/CDN later by setting `SERVE_MEDIA=0`.
- The storefront is the hostname Render assigns. To use a custom domain, add it
  in Render, add it to `ALLOWED_HOSTS` and `CSRF_TRUSTED_ORIGINS`, and add a
  matching `TenantDomain` for the kitchen in the Django admin.

## Not included

The WhatsApp message worker (`run_huey`) needs Redis and an always-on process;
add a Render Key Value instance and a background worker when WhatsApp sending
is turned on. The website and owner admin do not need it.

## Re-seeding

`python scripts/seed_local.py` with `SEED_ONLY_IF_EMPTY` unset **deletes and
rebuilds** the Annam demo kitchen. Never run it against a live database that
has real orders or owner edits.
