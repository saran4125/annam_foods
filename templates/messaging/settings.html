Connect n8n to this inbox

  1. In n8n, add an HTTP Request node using POST and this endpoint.
  2. Set Header Auth: Authorization: Bearer <your inbox sync token>.
  3. Copy incoming WhatsApp events to this endpoint with event: "meta".
  4. After n8n sends a reply successfully, copy its message body and Meta message ID to the same endpoint with event: "outbound".

Both copies are needed to show both sides of the conversation. Meta's delivery-status events alone do not include the text of n8n's replies.

Your Meta callback stays pointed at n8n. No new Meta callback, app secret or forwarding URL is required for inbox sync.
